# Easy Google Sheets Tab Search

## Description
The **Easy Google Sheets Tab Search** extension allows users to instantly search for tabs within Google Sheets documents. With a simple click on the search button or by pressing **Alt + S**, users can quickly find and navigate between the different sheets in their spreadsheet.

## Features
- Fast tab search functionality
- Quick access via the **Alt + S** keyboard shortcut
- Intuitive and minimalist interface
- Seamless integration with Google Sheets documents

## Installation
1. Visit the [Firefox Add-Ons Store](https://addons.mozilla.org) or the [Chrome Web Store](https://chrome.google.com/webstore) and search for "Easy Google Sheets Tab Search".
2. Click "Add to Firefox" or "Add to Chrome" to install the extension.
3. Follow the instructions to complete the installation.
